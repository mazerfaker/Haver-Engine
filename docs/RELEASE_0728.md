# Forge Engine v0.7.28 — Visual Channels & Audio Routing

Source candidate based on the exact v0.7.27 source archive. No new Cargo dependencies. No Auto Rig or automatic animator. The existing graphics and audio labs remain intact.

## Implemented in source (not compiled here)
- Independent scalar key Bezier easing (two normalized controls); optional serde field preserves old keys. Linear and Smooth are retained. Separate visual tracks for Scale X, Scale Y and Opacity, evaluated in clip-local time without modifying logical size, physics or base colour. Editor graph lets users move keys and set Bezier controls. Player, Bevy viewport, egui fallback and GPU lighting consume the visual channels. Animated-size objects bypass editor's old size-based culling. Transform X/Y/rotation tracks remain unchanged for legacy clips.
- Two fixed additional audio buses (Voice and Ambience) alongside Music and SFX under Master. Source route selected in Inspector; old music boolean remains fallback. F8 Player mixer has bus gain sliders and five source presets (Flat, Warm, Bright, Small room, Large room). Same presets in editor live preview. Streaming DSP target gains/room interpolate using 20 ms one-pole time constant, once per interleaved frame; state stays allocated. PCM16 WAV only; existing feedback/reflections, no full algorithmic reverb or arbitrary bus graph. Preview remains per-source.
- Batch trim of up to 1024 irregular atlas regions, with bounded estimated scan budget (64 Mi pixels). Decode once; preserve per-frame geometry; source texture unchanged. Fully transparent frames skipped. Store clip and save project to persist and sync metadata. No new atlas packing algorithm.
- GPU lighting uses conservative static blocker spatial index for 32–4096 blockers, 256-unit cells, large blockers global, full scan for wide queries; sorted deduplicated candidate IDs preserve original ranking tie order. Scratch vector reused per light query within a sync. Previous light grid and all WGSL preserved. No measured GPU improvement.
- Prefab Composer graph allows dragging direct-reference display nodes (session-only positions; not scene offsets). Recursive dependency viewer via explicit Refresh dependency tree, max 128 rows and 8 nested levels; path/cycle errors displayed, existing validation and backups retained. Not a freely editable recursive graph, no persistent graph layout. No new hierarchy merge policy.
- Global editor spacing and control widths unified; existing theme, icons, dock layouts preserved. Full visual redesign not complete.
