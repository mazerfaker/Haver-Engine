# v0.5 Gameplay PRO — experimental source

Save project before export. Gameplay PRO menu: choose Rapier, ambient and mixer gains, add HUD widgets, export bundle. Inspector: shapes, friction, mass, lights, particle presets and audio asset path. Audio files must already be copied into assets/ (OGG recommended); standalone plays configured sounds at startup. Tilemap tab accepts atlas columns/rows/frame; 4x4 autotile uses N/E/S/W bits 1/2/4/8. Keep same atlas for a layer. Nodes have named numeric variables, set/add/multiply and positive condition; graph positions serialized. Lua additions: find_object(name) -> ID, play_animation(name), spawn(name,x,y) -> rectangle, emit(name) -> log, timer(name,seconds) -> true once due. Old API retained. 

Known limitations: Rapier rebuilds collision world each step and preserves velocity, not contact caches; legacy trigger test is AABB and jump grounding is approximate; Lua vertical impulses and graph jumps are not integrated with Rapier velocity. No collider polygon or joints UI. Tile objects are not batched. Lighting is per-sprite tint with approximate occlusion, not normal maps or pixel shadows. Particles are simple CPU-generated rectangles, rebuilt each frame. Audio gains static at startup in standalone, no live editor playback. HUD button/label standalone only; no complete menu/inventory editor. Lua emit logs only; find_object returns ID not component handle; no arbitrary function nodes. Android/iOS builds not implemented. Full localization remains incomplete. All Rust code is uncompiled in this environment.
