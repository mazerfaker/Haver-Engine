# Forge Engine v0.7.38 — Onion Skin & Mixed PCM

Source candidate derived from exact v0.7.37 ZIP. No Auto Rig, automatic animator, or new Cargo dependencies.

## Changes and limits
- Animation Studio: textured previous/next onion ghosts, distinct tint, loop-aware frame stepping, first/last frame buttons, 0.25–8x zoom, drag pan and reset, per-object/clip session state, shared cursor and frame geometry. Frame step seeks the middle of the actual frame interval (including variable durations); no runtime events dispatched. Event lookup now uses min/max instead of allocating/sorting a list. No multi-frame onion count, no independent preview camera persistence.
- Asset relocation: previous destructive Move/Rename is intentionally replaced with Copy/Relink (keep original). The editor offers a fresh dependency scan and counts upstream documents and scan warnings; destination must be a new regular asset path with the same supported extension in an existing directory inside assets. Bounded copy, create_new, flush and sync, and cleanup on ordinary write failure. Active scene references for sprites, normal maps, particle textures and sound paths are changed only after copy succeeds. Original is retained, so saved scenes, external prefabs, atlas sidecars and dynamic Lua paths are not broken; no automatic project-wide rewrite or original deletion. Linked instances still require unlinking. Save scene after operation. Existing history/single-tab guard retained. Manual deletion is not recommended without checking external and dynamic references. This is non-destructive relocation, not a full transactional project-wide rename.
- Audio: PCM unsigned 8-bit, signed 16/24/32-bit and IEEE float32 WAV (format tags 1 and 3), mono/stereo, 8–96 kHz. Converted at load to internal PCM16 (quantizes higher bit depth; non-finite floats become zero). Limits: 8 MiB source/normalized data per source and existing 32 MiB scene budget. Mixed bit depths accepted for compatible cascade tracks. No resampling, channel conversion, WAVE_FORMAT_EXTENSIBLE or compressed format support in DSP; ordinary audio fallback unchanged. Same sample rate/channels/loop mode, equal looping lengths still required. Existing offline PCM16 export unchanged. Added RUN_MIXED_PCM_SCENE.bat (24-bit and 8-bit signals). F8 controls; cascade remains experimental and opt-in.
- Prefab: add or remove external links inside nested inline draft without deleting actual prefab files, select attachment parent and offsets using previous controls; existing save validation, cycle detection and backup. Linked scene refresh restrictions remain; no cross-file object transfer.
- Lighting/performance: ambient-only scene skips loading normal textures when no positive-radius lights exist; normal maps reload if lighting returns; existing eviction, material cache, GPU diagnostics and shader preserved. No measured FPS/RAM/VRAM improvement; no new shadow algorithm. 
- Stability: 75 Python tests (73 validation + 2 packing), including 4 new static tests; two new Rust tests authored, not executed. cargo check --locked attempted; cargo unavailable. No verified Rust compilation, Windows run, audio playback or GPU measurements. All inherited source/example files retained (changed files listed in patch).
