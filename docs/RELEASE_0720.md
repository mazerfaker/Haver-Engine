# Forge Engine v0.7.20 — Docking, Graph & Atlas

Base: exact published v0.7.19 source. New source has not been compiled in this environment. All old demo scenes and WGSL shaders are retained. No new dependencies, Auto Rig or automatic animation authoring.

## Implemented in source

- **Recursive docking:** opt-in in Studio → Recursive docking workspace (experimental). Real tree of horizontal/vertical splits and tab leaves for Scene, Inspector, Tools and Viewport, draggable split bars, tab dragging onto explicit Tab/arrow targets, automatic persistence after releasing pointer and manual Save dock tree. Reset dock tree restores default. The old zones/floating windows remain available; play mode uses legacy layout because the existing simulation advances in its viewport. Tree mode manages the four main panels, not arbitrary extra floating windows or OS-level docking.
- **Editor look:** slightly revised dark palette, consistent line-icon header for the viewport as well as existing panels. Not a complete Godot-style redesign or full icon replacement.
- **Animation Graph:** named clips are draggable nodes with persistent positions; click a source then target to add an explicit Moving transition, double-click to load a clip for preview; edit conditions, priorities and delete rules using the existing list. Wildcard transitions remain list-only. Maximum 64 shown nodes; no automatic rigging or animation generation.
- **Irregular Sprite Atlas:** import 1–256 PNG/JPEG frames in filename order via Assets → Pack frame images into atlas. Shelf packing up to 2048×4096 with transparent padding; normalized XYWH regions persisted per clip and used by existing UV consumers (Player, editor and GPU lighting). Convert grid to regions, edit region numbers, append regions or return to grid; Store clip saves edits. Object render dimensions are fixed, so differently sized source images are scaled to that object size; no trim/rotation metadata or rectangle drag handles yet. Existing Aseprite import unchanged.
- **Audio:** optional stereo positioning for SFX in Player through Bevy spatial listener and spatial sinks, preserving existing gain mixer, pitch and distance attenuation. The existing initial-scene audio loading behavior remains; no complete scene-lifecycle audio redesign. Audio → Offline WAV effects renders a separate asset (PCM16 mono/stereo 8–96 kHz, max 32 MiB), with 2-band crossover EQ and three decaying room-reflection taps. Selected object's Sound path changes to output if one is selected. This is offline processing, not a live EQ/reverb bus or convolution reverb. Existing preview remains available.
- **GPU vertex quads:** opt-in Gameplay PRO → GPU vertex quads. Same compute simulation and buffer format, new bounded mesh with 6 vertices per particle; vertex shader reads that slot's position and age. Fragment shader samples only its own texture and fade, no loop over all particles. This is an expanded mesh, **not hardware instancing** or an indirect draw pipeline. Cached meshes shared by matching particle counts; inactive counts evicted. Old fragment-loop renderer unchanged and remains default. Existing emitter and slot limits preserved; sorting/blending can differ. New WGSL is unvalidated on GPU.
- **Linked prefabs:** library insertion attaches source UUID, instance UUID and library filename. Refresh selected instance from its source manually; keep local identity, hierarchy, position, size, rotation and animation key positions. Explicit appearance, animation, physics, gameplay, scripts override groups. Refuses changed membership instead of deleting/replacing local objects. Ordinary duplicates/copy/paste clear links. Save As copies linked prefab source files (asset references in prefab sources not used in current scene may still require manual copy). Asset moves blocked while linked instances exist to avoid breaking library paths. No automatic hot sync, structural merging, per-property overrides or nested linked-asset recursion.
- **Profiler:** UI frame median and P95, expanded-quad triangle estimate and storage payload. These are not GPU timings, measured draw calls or total VRAM. No benchmark claims.
- **QA:** new static fixture for vertex quads and irregular atlas, old fixtures unchanged, additional Rust tests for docking, atlas packing/UV, linked prefabs and PCM processing. `prepare_lock.ps1` accepts root version 0.7.19 and changes only the root package version. Both new scenes included in editor model QA.

## Windows test order

1. Back up v0.7.19. Extract update into existing project root; keep `Cargo.lock` and `target`. Run `QUICK_CHECK.bat` (all targets plus GPU examples). Send `forge-quick-check.log` if nonzero.
2. Run `QUICK_BUILD.bat`, then `RUN_EDITOR_DEBUG.bat`. Verify legacy workspace, then enable Studio → Recursive docking workspace. Drag tabs between the Tab/arrow targets, resize splits, restart editor and verify persistence. In case of problems disable tree mode or use Reset dock tree.
3. `RUN_GPU_PARTICLES_SCENE.bat` (old renderer) and `RUN_GPU_QUADS_SCENE.bat` (new opt-in renderer); verify motion and fade, compare visually. `RUN_GPU_SCENE.bat` checks previous lighting.
4. `RUN_ATLAS_SCENE.bat`: A/D to switch Idle/Run, verify distinct colored atlas frames. Open examples/atlas_regions/project.forge.json in editor, select player, Tools → Animation. Test draggable graph and region edits. Store clip after changes.
5. Save a test project, save a subtree to Prefab library, insert linked copy, edit source via Edit prefab, save, then Refresh linked instance and test override checkboxes. Test stereo pan in Player with an SFX and offline WAV processing on a copy of a PCM16 WAV.
6. `CHECK_WINDOWS.bat` for compile and model QA, then `BUILD_WINDOWS.bat` only when checks pass.
