# Forge Engine v0.7.29 — Routing, Curve Controls & Index Cache

Source candidate based on exact v0.7.28 archive. No new Cargo dependencies; no Auto Rig or automatic animator. The previous GPU particle renderer and experimental labs remain intact.

## Added in source (not compiled)
- Up to 32 named audio gain groups with parent routing, gain and mute; groups terminate at Master or an existing Music/SFX/Voice/Ambience bus. Cycles and invalid parents are rejected. Source custom bus name is optional; missing names fall back to its original route. Master applied once. Editor Gameplay settings and F8 Player mixer expose controls. This is hierarchical gain routing, not a shared bus-level DSP/send graph; spatial policy follows the original source route.
- Separate optional streaming reverb: four parallel damped feedback delay lines (29/41/53/67 ms), independent of earlier room reflections, smooth parameter changes, atomically packed DSP control and per-channel histories. PCM16 only, preview and Player. Existing WAV projects default to zero reverb; offline WAV export remains dry/early-reflection EQ only. Fixed feedback/damping, no convolution, no custom impulse response. Added bounded per-source delay memory and extra DSP work; no performance measurement. Existing half-second nonlooping decoder tail remains.
- Selected scalar Bezier key segment displays two draggable vertical normalized controls (fixed time positions), numerical controls remain. Shift entire active channel in time while preserving key spacing and bounds. No arbitrary multiple-key selection or full two-axis Bezier handle editor.
- Batch import up to 128 PNG/JPEG, 16 MiB compressed per file, 128 MiB per batch, max 4096x4096 and 96 MiB decoder allocation limit; exact byte duplicates removed within batch only (hash then comparison), new directory, rollback on invalid input. Existing atlas packing unchanged. Asset-browser add from file uses image dimensions without full decode. Previous viewport texture cache remains.
- Lighting and blocker index caches compare ordered IDs and bit-exact bounds/radii, rebuild on changes, reuse query scratch across frames. Includes counters and last CPU indexing duration. Geometry lists still built each frame; no GPU timing or new shadow algorithm. Cache resets when lighting disabled. All existing WGSL unchanged.
- Prefab layout save/load to per-composition `.prefab.json.layout.json` sidecar keyed by reference UUID; bounds checked. Explicit Save/Load buttons, not auto-save. Recursive dependency viewer can select and open a referenced file after explicitly discarding current draft. No arbitrary editing of the whole recursive graph; source prefab transform data unchanged by layout operations.
- Editor shared heading typography and icon spacing updated, previous themes/docking intact. Full visual redesign not complete.
- Performance panel exports JSON with sorted UI frame samples, RSS (if available), estimated cache and particle payload, lighting index rebuild/reuse counters and CPU duration. GPU frame time and total VRAM explicitly null, not fabricated.
