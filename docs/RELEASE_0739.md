# Forge Engine v0.7.39 — Float32 Audio & Asset Transactions

Source candidate based on v0.7.38. No new Cargo dependencies. Auto Rig and automatic animator are outside this project. Windows compilation is not verified: cargo is absent in the build environment.

## Changes
- Animation Studio: independently choose 0–5 previous and 0–5 next Onion Skin frames, RGBA colors/opacity, distance fade, adjustable preview height 140–480 px. Existing zoom, pan, frame navigation, original texture, UV, pivots and synchronization retained. Repeated loop frames are drawn once; settings are session-local per object/clip.
- Runtime audio: supported PCM8/16/24/32 and IEEE Float32 WAV decoded into interleaved `Arc<[f32]>` directly; nonfinite values become zero, values limited to [-1,1]. Shared and cascade buses choose the highest source sample rate (8–96 kHz) and channel count (1–2) and linearly interpolate before playback. Mono duplicates to stereo. Downmix helper averages stereo, but automatic bus selection does not downmix. Decoder indexes samples instead of bytes; gains update on channel-zero boundaries. Still requires equal converted frame counts for looping groups, matching loop flags, nonspatial sources, normal speed and no per-source effects. Old normal playback fallback and offline WAV export retained. This is not band-limited resampling. Float32 uses more memory than PCM16; source cap remains 8 MiB, total decoded/converted shared buffer budget remains 32 MiB (temporary conversion output also budgeted); oversized inputs use fallback. Raw load/Arc conversion and DSP state have additional overhead. Live mode remains experimental/off by default.
- New example `examples/resampled_bus` includes 16 kHz mono and 48 kHz stereo PCM16, each 0.25s, with cascade enabled; `RUN_RESAMPLED_BUS_SCENE.bat` launches it. Existing mixed bit-depth example stays unchanged.
- Offline project-wide asset relocation: `tools/relocate_asset.py` (Python 3.10+, no external packages) scans saved root scenes, prefabs under `prefabs/` and generated atlas JSON under `assets/`. Updates exact recognized reference fields, moves matching atlas sidecar, removes stale caches, preserves byte-for-byte recovery backups. Source removed last. Dry-run by default. Rejects overwrites, symlinks/junctions, unknown literal references, unsupported extensions, path traversal, duplicate JSON keys and excessive input sizes. Other project roots are not rewritten. Dynamic Lua paths cannot be proven safe: script-bearing projects need explicit `--allow-dynamic` after manual review; known embedded/literal old references block even with override. Unknown arbitrary formats and history backups are not covered. Do not apply with editor/player open. Tool is offline CLI, not integrated into GUI; original non-destructive Copy / relink remains available. Atomic per-file replacement with recovery journal, not a filesystem-wide atomic transaction. Journal backups contain original project files and must remain private. New files use atomic exclusive hard-link publication (requires filesystem support, e.g. NTFS); on failure rollback or retain journal for manual recovery. Concurrent modifications are not supported; rollback refuses to overwrite unrelated changes. No automatic deletion of other assets.
- Prefab Composer: inline nested external link path replacement and ordering buttons preserve node UUID, parent and offsets. Existing save-time validation and backup path retained; cross-file game-object moves not added.
- Lighting: normal maps now loaded only for sprites with selected active lights, transparent tint skips candidate scoring. WGSL samples the single-mip normal texture at explicit LOD 0 after transparent/ambient-only early exits, and computes perpendicular only when shadow blockers exist. Existing five-sample soft-shadow algorithm preserved. GPU shader not compiled or rendered here. Actual FPS/RAM/VRAM improvements not measured.

## Relocation usage (close Forge first)
From the engine directory, substitute your own saved project root and asset paths:
```
py -3 tools\relocate_asset.py "D:\MyGame" assets/hero.png assets/characters/hero.png
py -3 tools\relocate_asset.py "D:\MyGame" assets/hero.png assets/characters/hero.png --apply
```
Destination directory must already exist. For script-bearing projects, review all dynamic references first and explicitly add `--allow-dynamic` if safe. The tool prints the journal path after successful commit. To restore, with editor closed:
```
py -3 tools\relocate_asset.py "D:\MyGame" --rollback "D:\MyGame\.forge-relocation-<id>"
```
If rollback reports a conflict, keep journal backups and reconcile manually. Reopen project and refresh Asset Database after apply/rollback. Do not remove the journal until the project has been verified.
